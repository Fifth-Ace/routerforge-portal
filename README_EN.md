# RouterForge Portal

Unified application UI inside Keenetic / Netcraze, part of the independent [RouterForge](https://github.com/Fifth-Ace/routerforge) ecosystem.

[Русский](README.md) · [Telegram](https://t.me/RouterForge)

## Install: GitHub first, no stores

- Chrome / Edge / Opera: [Tampermonkey](https://www.tampermonkey.net/) userscript, or use the native Chromium ZIP via Load unpacked in Developer mode.
- Firefox: Tampermonkey / Violentmonkey userscript. Unsigned native XPI is for temporary developer testing ONLY.
- [Userscript direct install](https://github.com/Fifth-Ace/routerforge-portal/releases/latest/download/routerforge-portal.user.js) (after first published Release).
- [GitHub Releases](https://github.com/Fifth-Ace/routerforge-portal/releases).

See [INSTALL-EN.md](docs/INSTALL-EN.md) for details. Do NOT enable both the native and userscript channels on the same Keenetic page. Settings can be migrated via JSON export/import.

No router firmware modification. Optional website permissions. Source and release assets are checked in CI; tagged artifacts get GitHub build attestations. Userscript manager auto-updates are NOT attestation-verified.
