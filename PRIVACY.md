# RouterForge Portal privacy (RU / EN)

## Русский

RouterForge Portal — локальное браузерное расширение. Сохраняет адреса роутеров, названия сервисов, URL (включая порты), выбранную тему и язык в локальном хранилище браузера. Данные не отправляются разработчикам и не используются для аналитики. Пароли не запрашиваются и не хранятся.

Запрос к GitHub API выполняется **только по кнопке проверки обновлений** и передаёт стандартные сетевые метаданные, включая IP-адрес, сервису GitHub; это регулируется политикой GitHub. Пользовательские адреса роутеров при этом не передаются. Пользователь может экспортировать или удалить локальные профили через настройки расширения.

## English

RouterForge Portal is a local browser extension. Router and application URLs (including ports), app names, theme and language are stored locally in your browser. No developer telemetry, analytics or password collection.

A request to GitHub API occurs **only when the user checks for updates**. GitHub receives normal network metadata, such as an IP address, under GitHub's own privacy practices. Router addresses are not included. Local profiles can be exported or deleted using extension settings.
